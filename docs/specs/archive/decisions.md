This file records decisions that have been **superseded**. When an architectural
decision is replaced, move the old decision here rather than silently deleting it,
so the history of why the system evolved is preserved.

## Rules

- Do **not** put current decisions here.
- When a decision in `../decisions/` is superseded:
  1. Copy its content into this file under a dated entry.
  2. Mark the original ADR status as `Superseded`.
  3. Update any dependent documents.
