# Audits

Audits are stored here when architectural, security, performance, or release
audits are performed.

Each audit should be a standalone Markdown document in this directory describing
the scope, findings, and any resulting actions. No fake audit results are
invented; this directory is empty until a real audit is performed.

## Planned Audit Types

- Architectural audits (vs. `../architecture/`)
- Security audits (vs. `../security/`)
- Performance audits
- Release audits (vs. `../planning/RELEASES.yaml`)
